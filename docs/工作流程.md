# 講座活動頁工作流程

本文件說明：場次如何同步、頁面如何建置、古文明圖文如何自動決定，以及 CMS 重貼範圍。

## 一、每次建置的流程

```
官網講座列表 (lv-24)
        ↓
scripts/sync-sessions.mjs
  · 抓取最新場次
  · 套用 overrides.js 排除已取消場次
  · 寫入 src/data/sessions/synced.js
        ↓
scripts/build-pages.mjs（npm run build）
  · 讀取 SESSIONS
  · 過濾「本月仍顯示」的場次
  · 古文明：依場次標題自動選圖文
  · 產出 dist/*.html
        ↓
scripts/build-paste.mjs（npm run build:paste）
  · 產出 官網貼上版/*/貼上用-HTML區塊.html
        ↓
手動貼回 CMS（網址不變）
```

常用指令：

```bash
npm run verify:ancient   # 可選：預覽古文明子主題解析結果
npm run build:all        # 同步場次 + 建置 + 產出貼上版
# 等同於先 sync 再 build:all：
npm run sync:all
```

> **注意**：`npm run build` 內建會先執行 `sync-sessions`，不必另外 sync 兩次。

GitHub Actions 於台灣時間 **09:00–17:00 每 2 小時** 自動 sync。有變更時下載 artifact `lecture-paste-html`，仍需**手動貼回 CMS**。

## 二、場次顯示／隱藏規則（全主題共用）

程式從 `synced.js` 篩出要出現在頁面上的場次：

| 條件 | 說明 |
|------|------|
| 本月場次 | 日期落在當月 |
| 尚未截止 | 報名截止日當天 15:00 前 |
| 尚未結束 | 場次結束時間已過則隱藏 |
| 未在取消清單 | `src/data/sessions/overrides.js` 的 `CANCELLED_LECTURE_FLOW_IDS` |

套用位置：總覽各主題「本月場次」、主題專頁場次表、講師陣列、報名區「最近一場」等。

主題分類（俄羅斯／拉丁美洲／極光／古文明）依講座**標題關鍵字**，見 `src/data/sessions/themeRules.js`。

## 三、古文明圖文自動化

俄羅斯、拉丁美洲、極光 → 使用 `src/data/themes.js` 固定圖文。

古文明為多國子主題，會依**本月剩餘古文明場次**自動決定素材：

```
本月仍顯示的古文明場次
        ↓
掃每場講座標題關鍵字
  （南亞、南印度、中亞、埃及…）
        ↓
src/lib/resolveAncientFocus.js
  · 副標 heroLead：只列出本月仍有場次的子主題
  · 主圖／文案：選命中次數最高的子主題 profile
        ↓
套用到：
  · 總覽 Hero 輪播（古文明那一格）
  · 總覽古文明主題大卡
  · 古文明專頁 Hero + Story
  · 其他主題頁「古文明」推薦小卡
```

子主題關鍵字、圖片、文案定義於 `src/data/sessions/ancientProfiles.js`。

檢查指令：

```bash
npm run verify:ancient
```

若標題無法對應任何子主題，會 fallback 到 `generic` profile，並在 build 時輸出警告。

## 四、CMS 重貼範圍

網址（`pv-157` 等）在 CMS 建立時固定；**重貼 HTML 區塊不會改網址**。

| 變更類型 | 建議重貼 |
|----------|----------|
| 場次增減／取消 | 總覽 + 受影響的主題專頁 |
| 古文明圖文邏輯或場次 | 總覽 + 古文明（極光頁若有古文明推薦卡也建議重貼） |
| 只改單一主題文案／樣式 | 該主題專頁 + 總覽（若總覽有該主題區塊） |
| 全站樣式或 MobileBar 等 | 五頁皆重貼 |

貼上檔案路徑：`官網貼上版/{總覽|俄羅斯|拉丁美洲|極光|古文明}/貼上用-HTML區塊.html`

## 五、手動維護檔案

| 檔案 | 用途 |
|------|------|
| `src/data/sessions/overrides.js` | 官網尚未下架、但頁面要先隱藏的場次（`lectureFlowId`） |
| `src/data/sessions/ancientProfiles.js` | 古文明各子主題關鍵字、圖片 URL、文案 |
| `src/data/themes.js` | 俄羅斯／拉丁美洲／極光固定素材；古文明 fallback |
| `src/data/sessions/themeRules.js` | 講座標題 → 主題分類關鍵字 |
| `src/data/cmsPages.js` | 五頁 CMS 路徑、SEO meta、貼上版路徑 |
| `src/data/faqs.js` | 各主題 Q&A（目前為靜態，未依場次動態化） |

---

## 六、尚未自動化的部分

- CMS 重貼（必須人工）
- 各主題 Q&A（`faqs.js`）
- 瀏覽器 title／description（`cmsPages.js` meta，未依場次動態改）
- 官網 lv-24 講座列表本身（需在官網後台維護；本專案僅讀取同步）

## 七、相關指令速查

| 指令 | 說明 |
|------|------|
| `npm run dev` | 同步場次後啟動本地預覽 |
| `npm run sync:sessions` | 僅同步場次 → `synced.js` |
| `npm run build:all` | 同步 + 建置 dist + 貼上版 |
| `npm run verify:ancient` | 檢查古文明子主題解析 |
| `npm run verify:paste` | 檢查貼上版完整性 |
| `npm run cms:meta` | 產出 CMS meta 設定參考 |
