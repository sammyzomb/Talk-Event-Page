# 官網輪播 HERO（1920×720）

## 檔案
- `1920x720-本月全台主題講座.html`：固定 1920×720 動畫預覽（背景四主題風景輪播＋文案進場）
- `1920x720-本月全台主題講座.png`：匯出後的靜態圖（給 CMS 輪播上傳）

## 用法
1. **看動畫**：用瀏覽器開啟 HTML（視窗請設成 1920×720 或縮放檢視）
2. **匯出靜態圖**：在專案根目錄執行  
   `npm run export:hero`

## 說明
多數官網輪播只吃 JPG／PNG；動畫請用 HTML 預覽或自行錄成短影片再上傳。
若要改文案、主題圖、或拆成四張主題輪播，跟我說即可。
